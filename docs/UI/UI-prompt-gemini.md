# 提示词（给 Gemini 出 UI 设计稿 · 逐页模板）

> **用法**：每轮复制下方代码块，只替换「# 本轮任务」段落；固定部分（角色/背景/风格规范/全局约束/输出要求）**一字不改**，保证跨页风格一致。投喂时附上一轮已定稿的页面图 + 组件规范表作为参照（图比文字锚定效果好）。

## 固定部分（每轮照抄）

```text
# 角色
你是一位资深微信小程序 UI/UX 设计师，擅长「现代极简 + 微国风」的商业化产品设计。

# 产品背景
产品名「众三思」，微信小程序。核心玩法：用户发布个人两难决策（决策单），邀请众人（群成员或公开网友）从「思危/思退/思变」三个角度提交观点评议；评议时限截止后生成决策报告，事后可复盘回看。定位：旁观者清的理性决策工具。Slogan：「集众人所见，众三思而后抉择」。

# 必须遵守的风格规范（B+微国风，已拍板不可更改）
- 色彩：操作主蓝 #4E75C9（主按钮、进度条、选中态）；品牌深蓝 #3B5BA5（文字链接、深色元素、报告页强调）；点缀 #B23C2E 印章红（仅用于状态/提醒语义：评议中徽章、截止提醒、按钮尾部红点落款）；页面底色 #F5F6F8；卡片纯白 #FFFFFF；文字 #22262E 主 / #9AA0AA 次，不用纯黑
- 字体：品牌层（导航标题、决策单标题、Slogan、报告封面）用宋体系衬线 + 2-4px 字距；功能层（正文、列表、表单、评议、Tab）用无衬线
- 形状：卡片圆角 16px、白底、轻投影；主按钮胶囊形（圆角 999px）操作主蓝底白字；徽章两种——状态类印章红底白字、常规标签浅蓝底 #E8EDF7 品牌深蓝字；图标线性 1.5px 描边；输入框/弹窗圆角 12-16px
- 国风边界：只允许「宋体标题、印章红状态徽章、按钮红点落款」；禁止古风纹理背景、印章大块面、装饰性图案
- 气质：克制、理性、留白充分；动效轻量（200ms 缓动）

# 全局约束
- 词汇红线：全端不出现「判官、申请、驳回、通过」；统一用「决策单、评议人、倾向某选项」
- 去责任化：报告、评议、结果页均需展示「建议仅供参考，最终决定权归你」
- 微信小程序规范：设计稿 750rpx 宽（按 750×1624 画布输出）、底部 TabBar（三思/群组/众思/我的）、刘海屏安全区适配

# 本轮任务
【在此替换：本页目标 + 布局要素 + 交互规则 + 跳转关系（从哪来/到哪去）+ 本页独有组件，内容取自页面设计方案 §3.x 对应章节】

# 输出要求
- 一张 750×1624 的高保真布局图（或等价 HTML/CSS 预览）
- 本页新增组件的规范表（配色/圆角/字号/尺寸/状态），与既有组件体系保持一致
- 全部中文标注，尺寸单位用 rpx
```

## 附录二 · 第 2 批「本轮任务」段（创建决策单）

> 用法：复制模板代码块，将【在此替换】占位段替换为下方内容。

```text
# 本轮任务（本批 1 页：创建决策单，subpackages/decision/create）
1. 创建决策单（表单页；跳转来源：三思/众思悬浮按钮、我的页快捷入口）
   - 表单自上而下：
     - 标题：单行输入，必填，≤30 字
     - 内容：多行输入，必填，自由描述两难处境；输入框内带隐私提示「不要填写身份证、手机号等隐私信息」
     - 图片：上传（相册/拍照），可选，最多 3 张
     - 备选方案：选项列表可增删，必填 ≥2 项
     - 评议时限：两段式时长选择器（小时 0–24 + 分钟 0/15/30/45），上限 24 小时，另设「不限」开关
     - 可见范围：三档单选（仅自己（草稿）/ 群内 / 公开）
     - 目标群：仅群内档显示，群选择器（任意自己所在的群），提供「现场新建群」入口
     - 评议人数上限：数字选择，最少 1；群内档 ≤ 当前群成员数、公开档 ≤ 100（随档位动态限制）
     - 标签：仅公开档显示，多选，最多 3 个，平台预置
   - 底部主按钮「发布」（操作主蓝胶囊 + 红点落款）：群内档提交即生效；公开档提交后进入「待审核」状态页；仅自己=存草稿
   - 群内档提交时发起订阅消息授权弹窗（评议时限到期提醒；拒绝则不发送任何提醒）
   - 强隐私场景引导选「群内」的提示位
```

## 附录三 · 第 3 批「本轮任务」段（决策单详情 + 观点填写弹窗）

```text
# 本轮任务（本批 1 页：决策单详情，subpackages/decision/detail）
1. 决策单详情（跳转来源：各列表页、群详情评议区）
   - 头部：发起人（昵称/头像）、发布时间、状态标签（草稿/待审核/评议中/已截止/已关闭/已复盘）、可见范围标识（群内/公开）
   - 内容区：标题（宋体）+ 正文 + 图片（最多 3 张，可放大预览）+ 标签
   - 票数区：评议时限内任何人不看票数汇总；截止后仅发起人可见汇总（引导跳报告页）
   - 评议区：
     - 已评议者：他人单条观点列表（含各自倾向），只读不可回复
     - 未评议者：观点列表折叠 + 提示「提交你的评议后，即可查看大家的观点」（先评后看）
     - 满员：评议入口显示「评议已满」，不再接收新评议
     - 各备选项按钮（评议中 + 未满员 + 非发起人时显示）→ 点击弹「观点填写弹窗」：所选倾向已带出 + 观点输入（不能为空，思危/思退/思变结构化引导）+ 提交
   - 发起人专属操作（按状态）：评议中=提前结束（确认弹窗：立即出报告）/关闭评议（确认弹窗：停止评议、不出报告）/删除决策单；已截止=查看报告/去复盘/删除；已关闭=归档查看/删除；已复盘=查看复盘档案
   - 评议时限倒计时展示（评议中时显示，到期前提醒位）
   - 状态与可见性：群内档非群成员提示不可见；被删除展示友好失效提示页
```

# 本轮任务（本批 2 页：决策报告 + 决策复盘）

「众三思」是微信小程序：用户发布个人两难决策，众人从「思危/思退/思变」三个视角评议，评议时限后出报告。定位是旁观者清的理性决策工具，Slogan「集众人所见，众三思而后抉择」。

# 品牌关键词（设计的所有决定都要回到这三个词）
1. 三思——品牌资产是「三」：产品名有「三」，评议有「思危/思退/思变」三个视角，决策讲究「三思而后行」
2. 众思——不是一个人拍脑袋，是众人的观点汇聚成参照
3. 慎决——理性、克制、留白，不喧哗、不娱乐化

# 设计方向（锁定一个主方向深挖，不要发散）
以「三」字结构为核心做现代图形化演绎：
- 三道横画是天然的设计母题，请给出 3 种解读并各出一稿：
  a) 三道横画 = 思危/思退/思变三个视角，横画之间有一点（决策点）贯穿——「三点一线，三思定夺」
  b) 三道横画上下错落 = 众人观点汇聚（「众」的抽象），中间横画突出（主见）
  c) 「三」嵌入方印（印章形外框）——国风落款感，图形化、非书法化
- 每个方案同时给出 1 个备选微调版（如横画圆角/断开/倾斜 15°）

# 硬性约束
- 色值只用三个：品牌深蓝 #3B5BA5（主）、操作主蓝 #4E75C9（次）、印章红 #B23C2E（点缀，单点使用，面积不超过整体的 10%）；白底稿和深蓝底反白稿都要成立

## 附录九 · 第 8 批「本轮任务」段（邀请落地页）

> 用法：复制模板代码块，将【在此替换】占位段替换为下方内容。

```text
# 本轮任务（本批 1 页：邀请落地页，subpackages/invite/landing）
1. 邀请落地页（跳转来源：群详情「邀请入群」生成的微信分享卡片/短效链接，被邀请者点开进入）
   - 顶部品牌区：产品名「众三思」（宋体）+ Slogan「集众人所见，众三思而后抉择」（灰小字）
   - 邀请信息卡：邀请人头像/昵称 +「{邀请人} 邀请你加入」+ 群头像、群名、成员数
   - 主按钮「加入群聊」（操作主蓝胶囊 + 红点落款）
   - 分状态流程（同一页按态切换，不拆多屏）：
     - 未登录：点击「加入群聊」触发静默登录建档 → 写入群成员关系 → 入群成功态
     - 已登录：点击直接入群 → 入群成功态
     - 邀请码失效/过期：展示「邀请已过期」失效提示 +「去众思广场看看」兜底出口
     - 群已解散：展示「该群已解散」不可进入提示
   - 入群成功态：印章红✓ +「已成功加入 {群名}」+ 双出口按钮「进入群详情」「随便看看」（新用户溯源记为邀请人属后台逻辑，本页不展示）
   - 底部：去责任化声明「建议仅供参考，最终决定权归你」
```

## 附录十 · 第 9 批「本轮任务」段（边界与失效态补充）

> 用法：复制模板代码块，将【在此替换】占位段替换为下方内容。本批均为依附已有页的**状态态**，按态切换不各拆整屏。

```text
# 本轮任务（本批 3 个补充态，分别挂在创建页 §3.3 与详情页 §3.4）
1. 公开档「待审核」结果态（创建页 §3.3 公开档提交后展示）
   - 顶部品牌区 + 居中信息态图标（浅蓝底 #E8EDF7，非印章红）+「已提交，正在审核中」
   - 说明文案：「通过审核后将出现在众思广场并接收评议」（不出现「待审核/驳回/通过」等红线词，对外文案用「审核中/暂未能发布」）
   - 出口按钮：「查看我的决策单」（跳决策单列表 scene=mine）/「回首页」
   - 审核未通过对应态：印章红提示 +「内容暂未能发布」+「去修改重提」（跳创建页带原内容）
2. 决策单失效提示页（决策单详情 §3.4，被删除/无权查看时展示）
   - 居中线性失效图标 + 友好文案「该决策单已失效或暂不可见」，不暴露技术原因
   - 出口「随便看看」（跳众思广场）/「回首页」；底部去责任化声明
3. 已复盘档案态（决策单详情 §3.4，status=已复盘）
   - 并列对照档案：上半「当初评议」（各评议人倾向 + 观点摘要）/ 下半「最终选择」（高亮备选项）+「实际结局」文本
   - 保留查看报告入口；发起人可回看，非发起人按先评后看与可见性规则展示
   - 底部：去责任化声明「建议仅供参考，最终决定权归你」
```
