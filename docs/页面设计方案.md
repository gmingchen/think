# 众三思 · 小程序页面设计方案（MVP）

> 本文依据 `需求设计方案.md`（唯一权威需求文档）与 `数据库设计.md` 做页面层落地：页面清单、页面要素、核心流程与状态展示规则。
> 只讨论「页面/交互要有什么」，不涉及具体视觉稿、组件实现与技术选型。若与需求条款冲突，以需求为准并回改本文。

## 一、全局框架

### 1.1 TabBar（4 个）

| Tab | 页面 | 职责 |
| --- | --- | --- |
| 三思 | pages/index/index | 发起决策入口、进行中决策单概览 |
| 群组 | pages/group/list | 群列表与建群入口（群详情/成员管理在分包） |
| 众思 | pages/square/index | 公开档决策单浏览、标签筛选 |
| 我的 | pages/mine/index | 我的决策单、复盘、历史归档入口 |

### 1.2 全局规则（映射需求 §三、§五）
- **登录策略**：进入小程序即**静默登录**（`wx.login` 换 `openid`，无感、无授权弹窗）；昵称/头像在需要时引导主动填写（微信头像昵称填写能力）。静默登录失败仍可浏览公开档；**发布与评议前必须已登录并填写昵称头像**，页面保留引导提示，不白屏。
- **词汇红线**：全端不出现「判官、申请、驳回、通过」；统一「决策单、评议人、倾向某选项」。
- **去责任化**：报告、评议、结果页、AI 兜底位置均展示「建议仅供参考，最终决定权归你」。
- **隐私防呆**：决策内容输入框、发布前提示「不要填写身份证、手机号等隐私信息」；强隐私场景引导选「群内」。
- **失效兜底**：决策单被删除后，任何入口再次进入显示友好提示页「该决策单已被发起人删除或不存在」。

### 1.3 主包与分包结构

主包仅含 4 个 Tab 页面，其余页面按业务模块拆入分包（降低主包体积、按需加载）：

```
pages/                            主包（4 Tab）
├── index/index                   三思
├── group/list                    群组
├── square/index                  众思
└── mine/index                    我的

subpackages/                      分包（按业务模块）
├── decision/                     决策单模块
│   ├── create/                   创建决策单
│   ├── detail/                   决策单详情
│   ├── list/                     决策单列表（群内/我的通用）
│   ├── report/                   决策报告
│   └── recap/                    决策复盘
├── group/                        群模块
│   ├── detail/                   群详情
│   └── members/                  群成员列表
├── invite/                       邀请落地
│   └── landing/                  邀请落地页
└── mine/                         个人中心模块
    └── profile/                  个人信息
```

> 每个页面文件夹内含 `index.{js,wxml,wxss,json}`；分包页面路径统一用 `subpackages/模块名/页面名/`。

### 1.4 UI 风格规范（B+微国风，商业化推荐）

**总则**：现代极简为骨（信任感、转化效率、可扩展），国风元素只进**品牌层与语义点缀**，不进功能层。

**色彩**：

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 操作主蓝 | `#4E75C9` | 主按钮、进度条、选中态（提亮一档，避免原黛蓝偏暗） |
| 品牌深蓝 | `#3B5BA5` | 文字链接、深色元素、报告页强调——深色场合保留原黛蓝 |
| 点缀色 | `#B23C2E` 印章红 | **仅状态/提醒语义**：评议中徽章、评议时限截止提醒、按钮尾部红点落款 |
| 背景 | `#F5F6F8` | 页面底色；卡片统一纯白 `#FFFFFF` |
| 文字 | `#22262E` / `#9AA0AA` | 主文字 / 次要文字（灰阶克制，不用纯黑） |

**字体**：

- 品牌层（导航标题、决策单标题、Slogan、报告封面）：宋体系衬线（`Songti SC` / `STSong` / `SimSun`），可加字距 2-4px
- 功能层（正文、列表、表单、评议、Tab）：系统无衬线（`PingFang SC` / 系统默认）

**形状**：

- 卡片：圆角 16px，白底，轻投影 `rgba(34,38,46,.06)`
- 主按钮：胶囊（`border-radius: 999px`），操作主蓝底白字，可带印章红点落款
- 徽章：状态用印章红底白字；常规标签用浅蓝底（`#E8EDF7`）黛蓝字
- 图标：线性图标 1.5px 描边；Tab 选中态黛蓝填充
- 输入框/弹窗：圆角 12-16px，白底

**国风点缀使用边界**：

- 允许：标题字体、印章红状态徽章、按钮红点落款、Slogan 排版
- 禁止：古风边框/纹理背景、印章大块面使用、装饰性图案（避免功能层视觉噪声）

**动效**：轻量过渡（约 200ms 缓动），克制使用；随机查看滑动、弹窗开关等交互动效不与国风元素叠加。

## 三、页面详细设计

### 3.1 三思（pages/index/index）

**页面目标**：发起决策的首要入口 + 个人决策概览工作台（对应 §4.1、§4.4）。

**布局要素（自上而下，参考审批类产品「引导→总览→状态→指标→提醒→行动」骨架）**：

- 顶部：居中产品名「众三思」（小字）+ 问候语「下午好，{昵称}」（次要文字）+ 核心引导大标题「今天有什么两难抉择？」（宋体大字，品牌层）
- 决策总览卡片：标题「共收获评议」+ 超大数字（视觉焦点）+ 辅助说明「累计发起 X 个决策 · 收到 Y 条评议」+ 底部统计行「评议中 a · 待复盘 b · 已完成 c」
- 评议中状态卡：✅「评议中的决策单」或「暂无评议中的决策」+ 右箭头 → 决策单列表（3.10，scene=mine）+ 描述「新的评议会在这里提醒你」
- 三指标卡片（横排等宽）：累计发起 / 收获评议 / 完成复盘（大数字 + 灰色小标签）
- 提醒条（浅蓝底 `#E8EDF7` + 信息图标）：评议时限到期提醒位「评议时限快到了，记得回来看报告」；无待提醒时展示去责任化声明「建议仅供参考，最终决定权归你」
- **悬浮「发起决策」按钮**（操作主蓝胶囊 + 红点落款）→ 跳创建页（subpackages/decision/create）

**交互规则**：

- 三思 Tab 无公开内容展示（公开浏览在众思 Tab），定位为个人工作台
- 总览卡片 / 状态卡 / 指标卡点击均可跳对应列表（3.10）；下拉刷新同步数据

### 3.2 众思（pages/square/index）

**页面目标**：最新公开决策单的浏览与评议入口（对应 §4.6）。

**布局要素**：

- 顶部：**标签筛选栏**（横向滚动，预置 10 个标签 +「全部」；单选，点击切换筛选）
- 列表：公开档决策单卡片流（仅审核通过的对外可见单，按发布时间倒序），**默认加载最新 50 个，上拉加载更多**
  - 卡片内容：标题 + 内容摘要（含图片缩略图，最多 3 张）、标签、状态（评议中/已截止）、评议人数进度（当前人数 / 上限）
  - **不展示票数汇总**（与 §3.3 隐藏汇总逻辑一致）
- **悬浮「发起决策」按钮**（同 3.1）→ 跳创建页
- **「随机查看」按钮**：随机抽一个「评议中」的公开决策单，弹窗展示

**决策单弹窗（列表点击与随机共用同一弹窗）**：

- 完整详情：正文 + 图片（可放大）+ 标签、发起人、发布时间、评议进度、状态
- 观点区与评议区：同详情页 3.4 规则（先评后看、点选项按钮弹窗写观点、观点不能为空、满员提示「评议已满」）——**弹窗内可直接提交评议，不跳页**
- **随机模式**：弹窗内**左右滑动**切换下一个随机单（底部「换下一个」按钮同步提供）
- **列表点击模式**：无滑动切换，仅关闭
- 发起人的管理操作（提前结束/关闭/删除）不在弹窗内，仍走详情页（3.4）

**交互规则**：

- 未登录可浏览列表与弹窗；提交评议前必须已登录并填写昵称头像（§1.2）
- 本页发起决策走悬浮按钮，其余专注浏览

### 3.3 创建决策单（subpackages/decision/create）

**页面目标**：决策单表单与发布入口（对应需求 §4.1）。

**表单要素（自上而下）**：

| 区块 | 要素 | 规则 |
| --- | --- | --- |
| 标题 | 单行输入框 | 必填，≤ 30 字 |
| 内容 | 多行输入框 + 隐私提示 | 必填；自由描述两难处境，不强制三思分段 |
| 图片 | 图片上传（相册/拍照） | 可选，最多 3 张；公开档须过图片审核 |
| 备选方案 | 选项列表，可增删 | 必填 ≥ 2 项 |
| 评议时限 | 两段式时长选择器（小时 stepper + 分钟档 0/15/30/45）+「不限」开关 | 上限 24 小时；0=不限，与人数不限不可同时选 |
| 可见范围 | 三档单选 | 仅自己（草稿）/ 群内 / 公开 |
| 目标群（仅群内档显示） | 群选择器 | 任意自己所在的群（不限群主）；提供「现场新建群」入口 |
| 评议人数上限 | 数字选择 | 最少 1；群内档 ≤ 当前群成员数、公开档 ≤ 100（随档位动态限制） |
| 标签（仅公开档显示） | 标签多选 | 最多 3 个，预置标签 |

**提交流程**：

- **群内档**：提交即生效 → 跳详情页（评议中），同时发起**订阅消息授权**（评议时限到期提醒；拒绝则不发送任何提醒）
- **公开档**：提交 → 进入「待审核」（对外不可见）→ 展示审核中状态页；审核不过退回可编辑态（提示修改点）→ 就地修改重提（不限次数）
- **仅自己**：保存为草稿，不发布、不产生评议

### 3.4 决策单详情（subpackages/decision/detail）

**页面目标**：决策单的阅读、评议、结果查看与发起人处置的单一入口（对应 §4.2、§4.3）。

**布局要素**：

- 头部：发起人（昵称/头像）、发布时间、当前状态标签、可见范围标识
- 内容区：标题 + 正文 + 图片（最多 3 张，可放大预览）+ 标签
- 票数区：**评议时限内任何人不看票数汇总**；截止后**仅发起人**可见汇总（引导跳报告页）
- 评议区：
  - 已评议者：展示他人单条观点列表（含各自倾向），只读不可回复
  - 未评议者：观点列表折叠，展示提示「提交你的评议后，即可查看大家的观点」（先评后看）
  - **满员展示**：评议人数达上限后，评议入口显示「评议已满」，不再接收新评议
- 评议区：展示各备选项**按钮**（评议中 + 未满员 + 非发起人时显示）——点击所选选项按钮 → **弹出观点填写弹窗**（所选倾向已带出 + 写观点，不能为空，思危/思退/思变结构化引导）→ 提交

**发起人专属操作（按状态）**：

| 状态 | 可用操作 |
| --- | --- |
| 评议中 | 提前结束（确认弹窗：立即出报告）、关闭评议（确认弹窗：停止评议、不出报告）、删除决策单 |
| 已截止 | 查看报告、去复盘、删除 |
| 已关闭 | 归档查看、删除 |
| 已复盘 | 查看复盘档案 |

**状态与可见性联动**：

- 群内档：非群成员提示不可见（已有评议记录者退群/群解散后仍可回看）
- 公开档：审核不通过的单不对他人可见；发起人看到退回可编辑态
- 已截止/已关闭：评议入口消失，评议人仍可回看本人当初那条评议
- 被删除：展示友好失效提示页

### 3.5 决策报告（subpackages/decision/report）

**页面目标**：发起人查看各选项票数汇总（对应 §4.3）。**仅发起人可见**，其他角色访问提示无权限。

**布局要素**：

- 各选项人数汇总（条形/数值展示，无精选、无点赞）
- 零评议时：展示 AI 三思参考（思危/思退/思变 + 各选项权衡），带「AI 内容仅供参考」标识
- 提前结束的单：展示「未满评议时限」标记
- 固定声明：「仅供参考，不代表最终建议，决定权在你」
- 底部：复盘入口（去回填结局）

### 3.6 决策复盘（subpackages/decision/recap）

**页面目标**：发起人回填结局，形成决策档案（对应 §3.5）。

**布局要素（并列对照式）**：

- 当初评议：各评议人倾向 + 观点摘要（实时读取，不做快照）
- 最终选择：单选备选项（可含「其他/未选」）
- 实际结局：多行输入（实际发生了什么）
- 提交后：决策单转「已复盘」，展示完整档案视图

### 3.7 我的群（pages/group/list）

**页面目标**：群列表页（对应 §4.5）。**纯列表**：建群入口 + 群列表，点击列表项进入群详情。

**布局要素**：

- 「+ 建群」按钮（输入群名即建）
- 群列表项：群头像、群名、成员数、我的角色（群主/成员）
- 已解散的群：展示「已解散」归档态，不再可进入

**交互规则**：

- 点击群列表项 → 进入群详情页（3.8）
- 邀请 / 退出 / 解散等管理操作不在列表页，统一收敛到群详情页（3.8）与成员列表页（3.9）

### 3.8 群详情（subpackages/group/detail）

**页面目标**：群信息展示与管理中枢（对应 §4.5）。

**布局要素（自上而下）**：

- 群信息区：群头像、群名、成员数（数字可点击 → 成员列表，见 3.9）
  - 群主：**修改群名称/群头像**、**邀请入群**按钮（内嵌生成短时效邀请链接/卡片——不落库，服务端结合 Redis 生成——微信分享）、**解散群**按钮
  - 成员：**退出群**按钮
- 评议区：该群「评议中」的决策单列表（卡片：标题、内容摘要、发起人、评议进度），点击进决策单详情
- 决策单列表入口：「查看全部」→ 决策单列表（3.10，scene=group，可按状态筛选）

**交互规则**：

- 解散群：确认弹窗提示「群内评议中的决策单将转为已关闭」，确认后群置「已解散」并退出本页
- 退出群：确认弹窗；退出后成员关系失效，已评议的决策单仍可回看
- 退出 / 解散入口在成员列表页（3.9）同样提供

### 3.9 群成员列表（subpackages/group/members）

**页面目标**：群成员展示与管理（对应 §4.5）。

**布局要素**：

- 顶部群组头部：群名称、成员数 + 操作图标按钮（邀请入群；群主见「解散」、成员见「退出」，与群详情同一套逻辑）
- 成员列表：头像、昵称、角色徽章（群主/成员）、入群时间；**服务端分页，滚动到底部自动加载更多**
- 群主视角：每位成员（除本人）提供**移除**操作（确认弹窗；群主本人不可被移除）

**交互规则**：

- 移除成员 = 同退群处理（成员关系失效），被移除者已评议的决策单仍可回看；移除后刷新头部成员数与成员列表
- 邀请 / 退出 / 解散：邀请复用群详情邀请弹窗；退出 / 解散走确认弹窗，成功后返回上级
- 入口来源：群详情页成员数点击进入

### 3.10 决策单列表（subpackages/decision/list）——群内 / 我的通用

**页面目标**：除广场外的决策单列表统一页面（对应 §4.4、§4.5），按 `scene` 参数切换数据源与顶部 Tab。

**场景定义**：

| scene | 入口 | 顶部 Tab | 列表数据 |
| --- | --- | --- | --- |
| group | 群详情「查看全部」（3.8） | 状态筛选：评议中（默认）/ 已截止 / 已关闭 / 已复盘 | 该群（`grp_id`）决策单 |
| mine | 我的页「我的决策单」（3.12） | 我发起的 / 我评议过的 | 见下 |

**mine 场景细化**：

- 「我发起的」：按状态归类——进行中（草稿含待审核/退回：继续编辑/重提；评议中：进详情、提前结束/关闭）＋已结束归档（已截止：看报告/去复盘；已关闭：归档查看；已复盘：看复盘档案）
- 「我评议过的」：本人提交过评议的决策单（含已退群/已解散群的单），点击进详情回看

**列表卡片**：与广场共用 `decision-card` 公共组件（标题、内容摘要、图片缩略图、标签、状态、评议进度）；点击进决策单详情（3.4）。

**交互规则**：

- 分页统一走 `paginationBehavior`（上拉加载更多）
- 群已解散后 group 场景不再可进入；已评议者仍可从 mine 场景回看自己参与过的决策单

### 3.11 邀请落地页（subpackages/invite/landing）

- 未登录：展示群信息 → 静默登录建档 → 写入成员关系 → 入群成功
- 已登录：直接入群
- 邀请即拉新：完成登录建档的新用户溯源记为邀请人
- 入群成功后引导跳转（群详情 3.8 或对应决策单）

### 3.12 我的（pages/mine/index）

**页面目标**：个人中心入口聚合（对应 §4.4）。

**布局要素（自上而下）**：

- 头部用户信息区：头像、昵称、加入时间（首次登录建档时间）；点击头部进入**个人信息编辑页**（3.13）
- 统计区：我发起的决策单数 / 参与评议数 / 收获评议数（实时统计）
- 功能入口：
  - 「发起决策」（快捷入口，同三思/众思悬浮按钮，跳创建页）
  - 「我的决策单」（决策单列表，scene=mine：我发起的 / 我评议过的，见 3.10）
  - 「我的群」（跳群列表）
  - 「客服」（微信客服会话，`open-type="contact"`）
  - 「关于」（**弹窗展示**：版本、免责声明、隐私政策）
- 底部：去责任化声明「建议仅供参考，最终决定权归你」

### 3.13 个人信息（subpackages/mine/profile）

**页面目标**：头像、昵称、性别的编辑（对应 §4.4）。

**布局要素**：

- 头像：微信头像选择（`open-type="chooseAvatar"`）+ 预设头像兜底
- 昵称：输入框（`type="nickname"`，微信昵称填写能力）
- 性别：单选（男 / 女 / 保密）——手动选择，不依赖微信授权（微信授权已不返回性别）
- 保存：校验通过后写入 `user` 表，返回后头部信息区即时刷新

## 四、核心流程

### 4.1 主流程：创建 → 评议 → 报告 → 复盘

```
创建决策单（表单 + 订阅授权）
   ├─ 群内档：提交即生效 ──────────┐
   └─ 公开档：提交→待审核→通过 ───┤
                                   ↓
                        评议中（评议时限倒计时）
        ├─ 评议人：登录+昵称头像→点选项按钮→弹窗写观点→提交→解锁他人观点
        ├─ 满员：评议入口显示「评议已满」
        ├─ 发起人提前结束 → 立即出报告（打「未满评议时限」标记）
        ├─ 发起人关闭评议 → 已关闭（不出报告）
        └─ 群解散 → 群内评议中决策单自动转「已关闭」
                                   ↓
                   已截止（自动生成报告，仅发起人可见）
                                   ↓
                     复盘回填（可选）→ 已复盘（档案闭环）
```

### 4.2 群管理链路

```
群列表 → 群详情（群信息 / 邀请入群 / 评议中列表）
          ├─ 成员数 → 成员列表（移除成员 / 退出 / 解散）
          ├─ 群主解散 → 群置已解散，群内评议中决策单转已关闭
          └─ 成员退出 → 成员关系失效，已评议决策单仍可回看
```

### 4.3 群邀请链路

```
群详情内嵌生成邀请链接 → 微信分享 → 点开落地页 → 静默登录建档（拉新溯源）→ 入群
                                              ↓
                               浏览群内决策单 / 提交评议
```

### 4.4 公开档审核链路

```
提交 → 待审核（对外不可见）
   ├─ 通过 → 进广场、开始接收评议
   └─ 不通过 → 退回草稿可编辑态 → 就地修改重提（不限次数）
```

### 4.5 订阅消息链路

```
创建时授权（一次性订阅额度 +1）
   → 评议时限到期扫描（status=1 且到期）
   → 有额度：发送提醒、额度 -1
   → 拒绝授权/无额度：不发送任何提醒（无站内降级）
```

## 五、状态 × 角色展示对照表

| decision.status | 发起人 | 已评议者 | 未评议者（群成员/网友） |
| --- | --- | --- | --- |
| 0-草稿（含待审核/退回） | 可编辑/重提；公开档看到审核状态 | 不可见 | 不可见 |
| 1-评议中 | 看单条观点（不看票数）；可提前结束/关闭/删除 | 看他人观点（先评后看）；截止前可改本人评议 | 可浏览；提交评议后解锁观点；满员时「评议已满」 |
| 2-已截止 | 看报告汇总；可复盘/删除 | 回看本人评议与观点列表；评议锁定 | 可浏览内容；报告仅发起人可见 |
| 3-已复盘 | 看完整档案 | 同已截止 | 同已截止 |
| 4-已关闭 | 归档查看；可删除 | 回看本人评议；不再接收评议 | 可浏览内容（群内档仍受成员资格限制） |
